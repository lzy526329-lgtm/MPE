# 云端小爪 · 桌宠内置小游戏

当前为原创 3D 单人平台跳跃游戏，可从 MPT 主窗口「玩法 → 云端小爪」或桌宠右键菜单「云端小爪」打开。游客可离线游玩，首次进入才加载 3D 场景。切换到其他功能或窗口进入后台时自动暂停并停止绘制，返回后点击「继续冒险」恢复当前一局。

## 操作

- 左键点击画面跳跃并启用鼠标自由视角；右键拖动也可转动镜头，滚轮调整远近。
- WASD / 方向键：随镜头方向移动；鼠标左键 / 空格：跳跃；Shift：加速。
- C：看向下一块平台；Q / E：键盘转动镜头。
- R：返回最近存档点；Esc：释放鼠标并暂停；点击「继续冒险」恢复。
- 窄屏或触屏显示方向按钮与跳跃按钮，可同时按住方向和跳跃，拖动画面转动视角。
- 右上角音符开启/关闭音效，音效默认关闭。

选择狐狸或兔子，沿 60 段路线绕山爬升到 503 米终点。五段区域包含盘山窄桥、错位石阶、移动落点、会带动角色的旋转横梁和旋转木杆。金色箭头标记下一块平台的落点。旋转木杆平台设有安全边缘，金圈和星星均在木杆扫不到的位置；碰到红色木杆只产生物理阻挡或推动，不会立即回档；掉出关卡才返回存档点（也可按 R 主动返回）。第 12、24、36、48 段自动存档，掉落后保留已收集星星。登顶后显示用时、星星、重试次数；新版盘山路线的最佳用时独立保存在本机，当前一局在应用关闭后不会保留。角色能力相同，仅外观不同。

## 开发与构建

在 MPT 仓库根目录运行 `npm run dev`，由应用玩法入口进入。Vite 的多页面入口为 `games/cloud-paws/index.html`；构建自动输出 `dist/games/cloud-paws/index.html`，脚本和样式均使用相对地址，随现有 Electron 安装包分发，不依赖另开服务器。

```sh
npm test
npm run test:cloud-paws
GAME_API_BASE_URL=https://YOUR_GAME_API_HOST npm run build:app
```

正式构建仍使用项目既有的账号 API 配置。`https://cloud-paws-test.invalid` 仅可用于离线本地构建检查，不得用于发布。

## 结构与验证

- `src/game.js`、`src/level.js`：Rapier 固定步长物理和关卡。
- `src/camera.js`：自由视角、镜头缩放与相机相对移动。
- `src/world.js`：Three.js 场景和原创程序化角色，无外部图片、字体、模型依赖。
- `src/main.js`、`src/style.css`：键盘/触屏、菜单、音效与界面。
- `src/host.js`：应用页面与系统窗口可见性合并，暂停后台游戏。
- MPT `src/cloudPawsPage.ts`：延迟创建内嵌页面，保留场景并同步页面可见性。

核心测试使用真实物理与开启的障碍逐段检查全部 60 段跳跃（允许等待平台角度），并覆盖相机方向、镜头限制、旋转/移动平台承载、存档、重生、暂停、通关和宿主切页。这是逐段可达性检查，不代表模拟了整局人工通关。宿主测试覆盖游客导航、延迟加载、场景保留、Windows/macOS 安装路径。
