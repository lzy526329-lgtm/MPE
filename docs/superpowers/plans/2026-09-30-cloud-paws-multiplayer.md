# Cloud Paws five-player implementation plan

Goal: 2–5 authenticated players share a room and a physical course, collide with each other, and finish in arrival order. Remove all collectible stars. Preserve solo practice, mouse jump, checkpoints, and fall-only automatic respawn.

Architecture: reuse the existing authenticated /ws/game channel and Electron main-process session. A single Rapier world per room simulates five dynamic player capsules at 60 Hz and publishes snapshots at 20 Hz. The iframe sends bounded input commands through a source-validated parent bridge; credentials never enter the iframe. Clients interpolate authoritative transforms. Six-character room codes, ready flags, host start, three-second countdown, disconnect grace/recovery, host transfer, leave and replay are in-memory room state. Server restart ends rooms cleanly. No deployment or release is included.
