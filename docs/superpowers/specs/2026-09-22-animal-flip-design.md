# 象狮虎豹：玩家对电脑

用户已确认玩法及 DOM/CSS 方案，并授权开始开发。

## 玩法

4×4 棋盘；红蓝各象、狮、虎、豹、狼、狗、猫、鼠一张。随机洗牌全部盖住；玩家红方先手，电脑蓝方。每回合翻一张暗牌，或将一张己方明牌上下左右移动一格（空位移动、敌牌攻击）。每次有效动作立即换边，无效操作不消耗回合。暗牌不可攻击，不能斜走、跨格、吃己方。大吃小，鼠可吃象且象不可吃鼠；同级双方消失。任一方无剩余牌则另一方胜；双方同时清空或当前方无合法动作则和局。剩余数包含未翻牌。

## 实现

采用现有 TypeScript + DOM/CSS，规则引擎独立于页面。电脑只接收隐藏暗牌身份后的观察状态，优先攻击、其次移动、最后翻牌；移动参考已知威胁和目标距离。电脑约 600ms 后行动，期间禁止玩家操作。离开页面暂停电脑计时；返回恢复；重开清除旧计时及选中项。棋盘、回合状态、双方剩余、最近动作、规则、重开与结束提示组成页面。沿用素材复古纸牌视觉，背景使用淡纸色，保持棋盘为主体。

## 边界

纯本地对局，无存档、联网、金币奖励和新增依赖。刷新重置，导航离开保留内存中的局。页面入口在主窗口玩法与宠物玩法菜单。所有内置图片使用逐段编码的相对 URL，兼容 macOS/Windows file://。

## 验证

规则用手工局面覆盖每回合动作、合法性、克制、同归于尽、终局、暗牌存活。AI 对隐藏身份替换保持相同决策。页面测试无暗牌身份泄漏、回合锁、重开/导航暂停计时；浏览器检查实际点击、图片载入、桌面与窄屏布局。运行全套测试、类型检查、构建，并检查构建内的资源及 file:// URL。
