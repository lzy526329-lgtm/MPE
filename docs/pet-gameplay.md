# MPT 宠物玩法设计文档

> 版本：v0.1（基础框架）  
> 目标：让「性格」与「状态」不只是展示字段，而是能逐步参与桌面宠物的行为与成长。

---

## 1. 设计目标

- 用户首次打开应用，自动获得一只**独一无二的宠物**（随机名字、性别、性格）。
- 宠物拥有**身份、成长、性格、状态、经济**五类数据，后续可扩展等级、称号、小游戏、互动奖励。
- 性格基于**四元素 × 十二星座**，既用于展示，也为行为差异提供规则基础。

---

## 2. 数据结构

```typescript
const pet = {
  // 身份
  id: 'pet_xxxxx',
  name: '小Q',
  gender: 'male',           // male | female
  title: '初来乍到',
  characterId: 'pet_001',

  // 成长
  level: 0,
  growth: 0,                // 成长值，后续用于升级

  // 生日
  birthday: '2026-08-20',     // 首次打开日期
  createdAt: '2026-08-20 15:23:11',

  // 性格
  personality: {
    element: 'fire',        // fire | earth | air | water
    zodiac: 'leo',          // 十二星座 id
    traits: ['热情', '行动力', '自信', '冲动'],
  },

  // 状态（越高越好，0~100）
  stats: {
    satiety: 100,           // 饱食度
    hygiene: 100,           // 卫生
    health: 100,            // 健康
  },

  // 经济（预留）
  coins: 0,
}
```

持久化位置：`userData/pet.json`。

## 3. 首次初始化规则

| 字段 | 规则 |
|------|------|
| id | `pet_` + 时间戳 + 随机串 |
| name | 从预设名字池随机 |
| gender | 随机 male / female |
| title | 固定「初来乍到」（Lv.0） |
| level | 0 |
| growth | 0 |
| birthday | 首次打开当天（本地日期） |
| createdAt | 首次打开时间 |
| personality | 随机元素 → 随机该元素星座 → 随机 2~4 个性格关键词 |
| stats | 饱食度 / 卫生 / 健康 均为 100 |
| coins | 0 |

| 元素 | 星座 | 常见性格关键词 |
|------|------|----------------|
| 🔥 火象 | 白羊座、狮子座、射手座 | 热情、行动力、自信、冲动 |

## 5. 状态系统（v0.1）

第一版采用「**饱食度 / 卫生先下降，健康作为结果属性**」的结构。

正常循环：

时间过去  
↓  
饱食度下降、卫生下降  
↓  
当二者过低  
↓  
健康才开始下降

### 5.1 自然衰减（按小时）

| 属性 | 初始值 | 什么时候下降 | 建议速度 |
|------|------:|--------------|---------:|
| 🍚 饱食度 | 100 | 随时间自然下降 | 每小时 -5 |
| 🛁 卫生 | 100 | 随时间自然下降 | 每小时 -2 |
| ❤️ 健康 | 100 | 不直接随时间下降 | 根据其他状态决定 |

### 5.2 饱食度阶段反馈

| 饱食度区间 | 状态描述 | 未来动画建议 |
|-----------|----------|--------------|
| > 60 | 正常 | `idle` |
| 30 ~ 60 | 有点饿 | `sad / idle` |
| 10 ~ 30 | 非常饿 | `hungry` |
| 0 ~ 10 | 饿坏了 | `weak` |

说明：第一版先实现数值与文案，动画状态先沉淀到设计文档，后续接 Spine 动作。

### 5.3 卫生变化

卫生比饱食度下降更慢，建议默认 **每小时 -2**。

未来还可叠加行为影响：

| 行为 | 卫生变化 |
|------|---------:|
| 普通待机 | -2 / 小时 |
| 吃饭 | -3 |
| 玩泥巴 | -5 |
| 玩小游戏 | -1 |
| 洗澡 | +30 |

形成循环：

吃饭  
↓  
饱食度增加  
↓  
卫生下降  
↓  
洗澡  
↓  
卫生恢复

### 5.4 健康扣减规则

健康不应“无缘无故掉血”，而应由其他状态驱动。

| 条件 | 健康变化 |
|------|---------:|
| 饱食度 ≥ 20 且卫生 ≥ 20 | 不下降 |
| 饱食度 < 20 | -1 / 小时 |
| 卫生 < 20 | -1 / 小时 |
| 饱食度 = 0 | 额外 -2 / 小时 |
| 卫生 = 0 | 额外 -2 / 小时 |

### 5.5 心情 mood

心情与三维状态分开，用于表达“这只宠物现在开不开心”。

```ts
🍚 饱食度 72
🛁 卫生   85
❤️ 健康   100
😊 心情   90
```

第一版里心情可作为**综合展示值**，主要受饱食度、卫生、健康影响；后续再接入行为事件。

未来事件示例：

| 事件 | 心情变化 |
|------|---------:|
| 喂食 | +10 |
| 洗澡 | +5 |
| 玩游戏 | +20 |
| 长时间没人理 | -5 |
| 很饿 | -10 |
| 很脏 | -10 |
| 生病 | -20 |

### 5.6 照顾操作

| 操作 | 效果 | 入口 |
|------|------|------|
| 喂食 | 饱食度 +35 | 设置页 / 右键菜单 |
| 清洁 | 卫生 +35 | 设置页 / 右键菜单 |
| 休息 | 健康 +25 | 设置页 / 右键菜单 |

### 5.7 离线计算

离线计算是桌宠“活着”的关键机制。

当用户关闭应用后，重新打开时需要用：

```ts
const hours = (Date.now() - lastUpdateTime) / 3600000

pet.stats.satiety -= hours * 5
pet.stats.hygiene -= hours * 2
```

再根据离线后的饱食度与卫生，决定健康是否下降。

示例：

- 晚上 10:00 关闭应用
- 当时：饱食度 80，卫生 90，健康 100
- 第二天早上 8:00 打开
- 离线 10 小时

结果：

- 饱食度：80 → 30
- 卫生：90 → 70
- 健康：100（仍可保持不掉）

这样玩家会感受到：**即使我不在，它也在生活。**

## 6. 性格对机制的影响（v0.1 已接入基础倍率）

性格在 v0.1 已影响**状态衰减倍率**，后续可继续扩展到行为与奖励。

| 元素 | 机制倾向（当前） | 未来扩展 |
|------|------------------|----------|
| 🔥 火象 | 饱食度衰减 ×1.1（更活跃、更易饿） | 更易主动玩耍、玩游戏收益更高 |
| 🌍 土象 | 状态衰减 ×0.85（更稳定） | 状态下降更慢、抗波动 |
| 🌬️ 风象 | 卫生衰减 ×1.1（更爱动/社交） | 互动奖励加成、小游戏额外奖励 |
| 💧 水象 | 低状态时健康惩罚 ×1.25 | 对卫生/健康更敏感、情绪变化更明显 |

## 7. 成长与经济（预留）

### 7.1 成长值 growth

- 来源（规划）：每日登录、完成提醒、小游戏、互动。
- 用途：累计到一定值升级，`level + 1`，解锁新称号或外观。

### 7.2 等级 level

| 等级 | 称号示例 |
|------|----------|
| 0 | 初来乍到 |
| 1 | 小伙伴 |
| 3 | 熟悉的朋友 |
| 5 | 可靠的伙伴 |
| 10 | 灵魂搭档 |

（称号表可在后续版本配置化。）

### 7.3 金币 coins

- 来源（规划）：小游戏、每日任务、成就。
- 用途（规划）：购买装饰、食物、清洁道具、特殊动画。

## 8. UI 信息架构

侧边栏 Tab：

1. **基础信息** — 名称、性别、称号、等级、生日、成长、性格
2. **形象** — Spine 角色选择
3. **外观与行为** — 显示、大小、自动行走
4. **状态** — 饱食度、卫生、健康 + 照顾按钮
5. **交流提醒** — 定时提醒

## 9. AI 对话系统

宠物状态数据（饱食度、卫生、健康、心情、性格）是接入 AI 对话的基础。AI 系统负责把这些数值**自然地表达**成宠物语言，而不参与数值计算。

详见：[宠物 AI 系统设计文档](./pet-ai-system.md)

## 10. 后续迭代建议

1. **行为层**：火象提高随机走动概率；水象低健康时播放特殊 idle 动画。
2. **提醒联动**：完成「喝水提醒」给予 growth / coins。
3. **生日系统**：生日当天弹特殊对话与奖励。
4. **性格重 roll**：消耗 coins 或达成成就后允许更换（需产品确认）。
5. **多宠物**：`pet.json` 升级为 `pets[]` + `activePetId`。

### 已实现：主动搭话（本地规则，不耗 token）

桌宠窗口开启时，按状态与互动间隔用模板冒气泡（不调 LLM）：

| 条件 | 文案倾向 | 冷却 |
|------|----------|------|
| 饱食度 < 25 | 喊饿、求喂食 | 全局约 30 分钟一次；同状态恢复前不重复 |
| 卫生 < 30 | 喊脏、求清洁 | 同上 |
| 健康 < 40 | 虚弱求照顾 | 同上 |
| 超过约 30 分钟无互动 | 寂寞求陪 | 互动后解除 |

实现：`electron/petProactiveChat.ts` + `tickProactiveChat()`。
